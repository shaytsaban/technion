④ BigQuery · דליי זמן ☁️

לקבץ לפי חודש ולפי יום בשבוע

נבנה את שני הגרפים הנפוצים ביותר ב-BI: הכנסה לכל חודש, וכמה הזמנות בכל יום בשבוע.

  1. פתח את BigQuery Sandbox והתחבר עם חשבון Google.
  2. הרץ את שאילתה א' — הכנסה חודשית (DATE_TRUNC).
  3. הרץ את שאילתה ב' — הזמנות לכל יום בשבוע (EXTRACT DAYOFWEEK; 1=ראשון … 7=שבת).
א' · הכנסה חודשית
-- DATE() הופך חותמת-זמן לתאריך, DATE_TRUNC מעגל לתחילת החודש
SELECT
  DATE_TRUNC(DATE(created_at), MONTH) AS month,
  ROUND(SUM(sale_price)) AS revenue
FROM `bigquery-public-data.thelook_ecommerce.order_items`
GROUP BY month
ORDER BY month;
ב' · הזמנות לפי יום בשבוע
SELECT
  EXTRACT(DAYOFWEEK FROM created_at) AS day_of_week,
  COUNT(*) AS items
FROM `bigquery-public-data.thelook_ecommerce.order_items`
GROUP BY day_of_week
ORDER BY day_of_week;

⑤ BigQuery · חשבון תאריכים ☁️

הפרשי תאריכים וסינון תקופה

DATE_DIFF נותן הפרש בימים; DATE_SUB מזיז תאריך אחורה — מושלם ל"30 הימים האחרונים".

  1. הרץ את שאילתה ג' — זמן המשלוח הממוצע (DATE_DIFF בין הזמנה למסירה).
  2. הרץ את שאילתה ד' — כמה פריטים נמכרו ב-30 הימים האחרונים שבנתונים.
ג' · זמן משלוח ממוצע (ימים)
-- הפרש הימים בין מסירה להזמנה, בממוצע
SELECT
  ROUND(AVG(DATE_DIFF(DATE(delivered_at), DATE(created_at), DAY)), 1) AS avg_delivery_days
FROM `bigquery-public-data.thelook_ecommerce.order_items`
WHERE delivered_at IS NOT NULL;
ד' · מכירות ב-30 הימים האחרונים
-- מעגנים ל-30 יום לפני התאריך האחרון בנתונים (תת-שאילתה ממודול 8)
SELECT COUNT(*) AS recent_items
FROM `bigquery-public-data.thelook_ecommerce.order_items`
WHERE DATE(created_at) >= DATE_SUB(
  (SELECT MAX(DATE(created_at)) FROM `bigquery-public-data.thelook_ecommerce.order_items`),
  INTERVAL 30 DAY
);

⑥ BigQuery · מגמות ☁️

צמיחה חודש-מול-חודש, ורבעונים

החיבור של הכול: מקבצים לפי זמן (CTE ממודול 8), ומשתמשים ב-LAG (מודול 7) כדי להשוות כל חודש לקודם. זה בדיוק גרף הצמיחה בכל דשבורד.

  1. הרץ את שאילתה ה' — אחוז צמיחה חודש-מול-חודש.
  2. הרץ את שאילתה ו' — הכנסה לכל רבעון (EXTRACT של שנה ורבעון).
ה' · אחוז צמיחה חודש-מול-חודש
WITH monthly AS (
  SELECT DATE_TRUNC(DATE(created_at), MONTH) AS month,
    SUM(sale_price) AS revenue
  FROM `bigquery-public-data.thelook_ecommerce.order_items`
  GROUP BY month
)
SELECT
  month,
  ROUND(revenue) AS revenue,
  ROUND(
    (revenue - LAG(revenue) OVER (ORDER BY month))
    / LAG(revenue) OVER (ORDER BY month) * 100, 1
  ) AS growth_pct
FROM monthly
ORDER BY month;
ו' · הכנסה לכל רבעון
SELECT
  EXTRACT(YEAR FROM created_at)    AS year,
  EXTRACT(QUARTER FROM created_at) AS quarter,
  ROUND(SUM(sale_price)) AS revenue
FROM `bigquery-public-data.thelook_ecommerce.order_items`
GROUP BY year, quarter
ORDER BY year, quarter;
✅ שאילתה ה' מאחדת שלושה מודולים: דלי זמן (CTE), פונקציית חלון (LAG), וחישוב אחוז. זה בדיוק הקוד שמאחורי מדד ה-MoM בכל דשבורד ניהולי.

סיימת — אתה מנתח לאורך זמן

  • תאריך = סוג מיוחד: אפשר להוציא ממנו חלקים ולעשות בו חשבון
  • EXTRACT = חלק (שנה/חודש/יום) · DATE_TRUNC = עיגול לדליים (לקיבוץ)
  • DATE_DIFF = הפרש ימים · DATE_SUB/ADD = הזזת תאריך (סינון תקופה)
  • צמיחה חודש-מול-חודש = DATE_TRUNC + CTE + LAG — חיבור של שלושה מודולים
  • תמיד לעגל זמן לדלי לפני GROUP BY — אחרת כל שנייה היא קבוצה
