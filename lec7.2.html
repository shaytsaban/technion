⚙️ Up-To-Date Advanced Cockpit Options

Modern Google AI Studio Options Explained 🧬

Google AI Studio features advanced engineering parameters. Here is exactly what they do, explained in simple terms:

🧩 The Three Prompt Types

  • **Chat Prompts**: Multiturn structured conversations (best for back-and-forth dating coaches!).
  • **Freeform Prompts**: Open-ended test sheets where you can inject images, files, and customizable variables using the `{variable_name}` syntax.
  • **Structured Prompts**: A table list of training examples (Input / Output pairs) to teach the model how to follow patterns.

🔒 Safety Settings Panel

Sliders that let you control content safety (Harassment, Hate Speech, Sexually Explicit, Dangerous Content). For a dating app chatbot, setting safety filters ensures the assistant stays **wholesome, polite, and encouraging**!

⚡ JSON Output & Custom Schemas

You can configure the **Output MIME Type** to `application/json` and define a strict **JSON Schema**. This forces the model to respond in machine-readable files so your dating app can load dates instantly:

{ "compliment": "Your energy lights up the entire park! 🎡", "dateIdea": "A classic strawberry ice cream walk near the lake.", "politeCheckPassed": true }

📈 Top-P & Top-K Sampling

- **Top-K**: Tells the brain to choose only from the top K most likely words. - **Top-P**: Limits word selection to a cumulative probability threshold. Keep these at default values (Top-P = 0.95, Top-K = 40) for standard, smooth dating advice!

🎯 Level 4: Writing Cupid's Prompts

How to Write the Magic Dating Prompts ✏️

To train our Matchmaker Bot, we need to paste a highly practical prompt into the **System Instructions** box. Here are the exact words that make it smart:

You are Cupid's Assistant, the ultimate friendly Dating Coach! Your job is to help users in our dating app: 1. Write polite, kind compliments (avoid boring opening lines like "hey"). 2. Recommend sweet and simple date ideas (like chocolate ice cream, mini-golf, or walks in the park). 3. Remind users to always be polite, respectful, and friendly to others. Always reply with encouraging words and dating emojis like 🍦, 💘, 💌, and 🎡!
💡 **Why does this prompt work?** It defines **who** the bot is (Dating Coach), **what** it does (compliments, ice cream date ideas), and **how** it behaves (encouraging, kind).

💻 Level 6: Code Integration

How to Connect the Brain to Your App! 🔗

Once your bot works, click **"Get Code"** in AI Studio and paste the starter script into your website. Here is how simple the code is to run:

// 1. Import the Google Gemini Brain library import { GoogleGenAI } from "@google/genai"; // 2. Initialize it using your secret API Key const ai = new GoogleGenAI({ apiKey: "YOUR_SECRET_GOOGLE_STUDIO_KEY" }); // 3. Call the dating coach model with your instructions! const response = await ai.models.generateContent({ model: "gemini-1.5-flash", contents: "Tell me a fun compliment to send to my match!", config: { systemInstruction: "You are Cupid's Assistant, the ultimate friendly Dating Coach...", temperature: 0.7, // Higher creativity for creative compliments! } }); console.log(response.text); // Out pops a beautiful compliment! 💌
