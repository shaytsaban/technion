ארבע רמות חישוב: על מה הנוסחה רצה

שתי נוסחאות נראות אותו דבר, אבל אחת נותנת 52.55% והשנייה 50.98%. אחת מגיבה למסנן והשנייה לא. ההבדל הוא לא בסימנים שכתבתם. ההבדל הוא באיזה שלב Tableau מריץ את הנוסחה ועל אילו שורות. מי שיודע את זה לא מנחש, הוא קורא את הנוסחה ויודע מה היא תחזיר.

רמת חישוב: השלב והקבוצה של השורות שעליהם נוסחה רצה. יש ארבע: שורה, צבירה, רמת פירוט (LOD) ו-חישוב טבלה. דוגמה: [Unit Price] * [Quantity] רצה על כל שורת מכירה בנפרד, ו-SUM([Sales]) רצה על כל השורות של סימן אחד בגרף.

נעקוב אחרי שש שורות אמיתיות מהקובץ של Scoop & Go (שלושה סניפים, שתי מכירות בכל אחד, כולן עם הנחה של 10%), ונראה את ארבע הרמות אחת אחרי השנייה.

  1. שש שורות. בכל אחת מחיר, הנחה ומכירה. הצבע מסמן סניף.
  2. רמת שורה. Net Price = [Unit Price] * (1 - [Discount]) רצה על כל שורה לבד, לפני שמסכמים משהו. יש שש שורות, ולכן שש תוצאות.
  3. צבירה. הגרף מציג סניף לכל סימן. SUM([Sales]) מתכנס לשלושה סימנים: 100.8, 57.6 ו-37.8. נוסחה כמו SUM([Profit]) / SUM([Sales]) רצה פה, על קבוצת השורות של הסימן.
  4. רמת פירוט (LOD). { FIXED : SUM([Sales]) } מחושב בנפרד, על כל הטבלה (196.2), ומוצמד בחזרה לכל סימן. כך אפשר לחשב את הנתח של כל סניף: 100.8 חלקי 196.2 הם 51.4%.
  5. חישוב טבלה. RANK(SUM([Sales])) לא נוגע בשורות המקור. הוא מסתכל על שלושת הסימנים שכבר חושבו ומדרג אותם. לכן הוא רץ אחרון, וכל שינוי במה שמוצג משנה אותו.

עשר נוסחאות על נתוני Scoop & Go. בחרו לכל אחת את הרמה. אחרי כל תשובה תראו למה.

הדמיה בדפדפן. היא לא מריצה Tableau, היא רק בודקת שאתם מזהים את הרמה.

ארבע רמות בגרף אחד, ומה קורה כשמסננים

  1. צרו שדה מחושב Net Price (רמת שורה): 
    [Unit Price] * (1 - [Discount])
    למה: מחיר אחרי הנחה, לכל שורה בנפרד.
  2. צרו Check Sales (צבירה של ביטוי ברמת שורה): 
    SUM([Net Price] * [Quantity])
    למה: בדיקת שפיות. אם הכול נכון, הסכום חייב להיות שווה ל-SUM([Sales]).
  3. צרו Margin % (צבירה): 
    SUM([Profit]) / SUM([Sales])
  4. צרו Share of Network (שימוש ב-LOD): 
    SUM([Sales]) / ATTR({ FIXED : SUM([Sales]) })
    למה: המכנה הוא סך כל הרשת, ללא קשר למה שמוצג.

ארבע פונקציות

REGEXP_MATCH(טקסט, תבנית): מחזירה אמת אם התבנית נמצאת איפשהו בטקסט, ושקר אם לא. דוגמה: REGEXP_MATCH("call 050-555-0101", "05[0-9]-[0-9]{3}") היא אמת.
REGEXP_EXTRACT(טקסט, תבנית): מחזירה את מה שהקבוצה הראשונה תפסה, או NULL אם אין התאמה. דוגמה: REGEXP_EXTRACT("Order SG-01234", "(SG-[0-9]{5})") היא SG-01234.
REGEXP_EXTRACT_NTH(טקסט, תבנית, מספר): כמו הקודמת, אבל בוחרת איזו קבוצה להחזיר. 0 הוא כל ההתאמה, 2 היא הקבוצה השנייה. דוגמה: REGEXP_EXTRACT_NTH("abc 123", "([a-z]+) ([0-9]+)", 2) היא 123.
REGEXP_REPLACE(טקסט, תבנית, החלפה): מחליפה את מה שהתאים בטקסט אחר. דוגמה: REGEXP_REPLACE("call 050-555-0101", "05[0-9]-[0-9]{3}-[0-9]{4}", "[phone]") היא call [phone].

תנאים: קודם מתכננים, אחר כך כותבים

מנהלת השירות מבקשת סדר טיפול. אם יש לקוח שביקש החזר והשאיר טלפון או נתן דירוג נמוך, מתקשרים אליו. אם ביקש החזר בלי טלפון, מטפלים בהחזר. אם רק נתן דירוג נמוך, קוראים ומגיבים. מי שאין לו אות בכלל לא נכנס לתור. כל השאר בסדר. זה אלגוריתם של חמש שורות, ויש בו מלכודת אחת: הסדר.

תנאי מקונן (IF עם ELSEIF): רשימה של בדיקות שמתבצעות מלמעלה למטה, והראשונה שמתקיימת קובעת את התוצאה. מה שמתחתיה לא נבדק. דוגמה: IF [Rating] <= 2 THEN "Review" ELSE "Fine" END.

  2. משמאל הדירוג הנמוך נבדק ראשון. הוא מתקיים, והתוצאה נקבעת: ״בדיקה בלבד״. שלושת התנאים שאחריו לא נבדקים אף פעם.

מה התבנית הנכונה לטקסט 21/05/2025 12:10?

מתי CASE מתאים יותר מ-IF?

CASE בנוי להשוואה של ביטוי אחד לערכים מדויקים. טווחים, כמה שדות וערכים ריקים מתאימים יותר ל-IF.
🎓 למרצה: כל המספרים (145 דקות, 320.5, 1,290, 15, הספירה לפי חודש ושעה, 10/6/3/3/2 ו-11/10/3) חושבו בפייתון מ-24 השורות. לבדוק בתוכנה לפני השיעור: (א) האם DATEPARSE על תא ריק ב-Resolved מחזירה Null (סביר, לא אומת). (ב) מה קורה בתבנית שגויה כשהיום גדול מ-12: Null או גלגול לתאריך אחר. (ג) מה ש-IF עושה כשהתנאי Null: הדף הרשמי של הפונקציות הלוגיות לא אומר, ולכן הנוסחה שלנו שומרת על Null בשורה הראשונה במפורש. (ה) DATEPARSE מוגדרת ב-Tableau לפי תיעוד לקבצי טקסט שאינם legacy ולמיצויים, וזה המצב ב-Public.

תבנית 1: חץ מגמה שיודע מה לעשות כשאין שנה קודמת

ארבעה שדות, כל אחד עושה דבר אחד. פרמטר קובע איזו שנה להשוות.

// Year Param: פרמטר, Integer, List: 2024, 2025, ערך נוכחי 2025

// Sales CY
SUM(IF YEAR([Order Date]) = [Year Param] THEN [Sales] END)

// Sales PY
SUM(IF YEAR([Order Date]) = [Year Param] - 1 THEN [Sales] END)

// YoY %
IIF(ZN([Sales PY]) = 0, NULL, ([Sales CY] - [Sales PY]) / [Sales PY])

// KPI Arrow
IF ISNULL([YoY %]) THEN "●"
ELSEIF [YoY %] > 0 THEN "▲"
ELSEIF [YoY %] < 0 THEN "▼"
ELSE "●"
END

השורות שמתחילות ב-// הן הערות. Tableau מתעלם מהן, ואנחנו משתמשים בהן כדי לתת לכל שדה שם בתוך הקוד.

חץ מגמה לפי סניף

  1. צרו את הפרמטר Year Param: בחלונית Data לחצו על החץ הקטן ליד תיבת החיפוש ובחרו Create Parameter.... בחלון: Name הוא Year Param, Data type הוא Integer, ב-Allowable values בחרו List והקלידו 2024 ו-2025, Current value 2025, ואז OK. הפרמטר מופיע באזור Parameters בתחתית החלונית. לחיצה ימנית עליו, Show Parameter. למה: הצופה בוחר שנה, ולא צריך לשכפל גיליון.
  2. צרו ארבעת השדות מהבלוק למעלה. למה: כל אחד נבדק בנפרד, ואם משהו נשבר רואים איפה.

  4. מיינו לפי Sales CY יורד.
  5. החליפו את הפרמטר ל-2024.

תרחיש (what-if): חישוב שבו חלק מהקלט הוא פרמטר, כדי לראות מה יקרה אם ערך אחד ישתנה. דוגמה: מה יקרה למכירות אם כל הנחה גדולה מ-20% תוגבל ל-20%. הפרמטר הוא התקרה.
// Discount Cap: פרמטר, Float, List: 0.5, 0.3, 0.2, 0.1, 0
// Price Change: פרמטר, Float, List: -0.1, -0.05, 0, 0.05, 0.1

// Scenario Sales
SUM([Quantity] * [Unit Price]
    * (1 - IIF([Discount] > [Discount Cap], [Discount Cap], [Discount]))
    * (1 + [Price Change]))

// Scenario Profit

// Scenario Margin
[Scenario Profit] / [Scenario Sales]

שימו לב: Cost לא משתנה, כי התרחיש משנה רק מחיר ומבצעים. ובעיקר: הכמות לא משתנה. זו הנחה, ואפשר לשאול אם היא סבירה.

הטמעה בדף משלכם: Embedding API v3

הדשבורד של Scoop & Go מפורסם ב-Tableau Public, ומנהלת השיווק רוצה אותו בתוך הדף של הרשת, ליד הטקסטים של החברה. לא קישור שפותח לשונית אחרת, אלא הגרף עצמו בתוך הדף. מכאן מתחיל החלק שמעבר ל-Tableau: דף אינטרנט שלכם, וקוד JavaScript שמדבר עם הגרף.

Public ועוד כלי חינמי מבחוץ צריך עורך טקסט, דפדפן, וכדי לפרסם גם חשבון GitHub חינמי (סעיף 8).

Embedding API v3: ספריית JavaScript של Tableau שהופכת את התגית <tableau-viz src="..."> לגרף חי בתוך הדף שלכם, ונותנת לקוד של הדף לשלוט בו: לסנן, להחליף פרמטר ולהאזין לפעולות הצופה. דוגמה: שלוש שורות HTML מציגות גרף שפורסם.

איפה לוקחים את הקישור

אחרי שמפרסמים ל-Tableau Public, בדף הגרף לוחצים Share. נפתח חלון עם שני שדות: Embed Code ו-Link.

אל תדביקו את Embed Code. בבדיקה שנעשתה באוקטובר 2026 השדה הזה עדיין נתן קוד של הגרסה הישנה של הספרייה (viz_v1.js), שמסומנת בתיעוד של Tableau כמיושנת. היא עדיין עובדת, אבל כל מה שבמודול הזה מבוסס על הגרסה החדשה. מעתיקים את ה-Link, ובונים סביבו את <tableau-viz>. הצורה של הקישור: https://public.tableau.com/views/WORKBOOK/SHEET?.... חלק מהכתובת שאחרי הסימן ? אפשר להשמיט.

עשר שורות. הגרף כאן הוא דוגמה של Tableau עצמה (Superstore_24), כדי שתראו שזה עובד לפני שתחליפו בגרף שלכם.

שלושה דברים שחשוב להבין בו:

  1. type="module" חובה. הספרייה כתובה כמודול ES, ובלי זה הדפדפן לא יריץ אותה.
  2. כתובת הספרייה מקובעת לגרסה 3.16.0. למה, בהמשך.
  3. אפשר להשמיט את הכתובת הארוכה של ה-Link. מספיק https://public.tableau.com/views/WORKBOOK/SHEET.
  1. הדפדפן טוען את הדף שלכם. התגית <tableau-viz> עדיין תגית ריקה, כי אף אחד לא יודע מה זה.
  2. שורת ה-import טוענת את ספריית ההטמעה. בגרסה מקובעת, 3.16.0.
  3. הספרייה מלמדת את הדפדפן מה זה tableau-viz, ובונה iframe שמצביע על הגרף ב-public.tableau.com.
  4. הגרף נטען. כשהוא מוכן לאינטראקציה, הספרייה שולחת לדף אירוע firstinteractive.
  5. הקוד שלכם קורא לשיטה, למשל applyFilterAsync, והבקשה עוברת לגרף.
  6. הגרף מצייר מחדש, ושולח אירוע filterchanged לדף. ככה הדף יודע מה קרה גם כשהצופה לחץ בגרף בעצמו.

"""Clean messy_tickets.csv so Tableau Public can read it.

Run:  python clean_tickets.py messy_tickets.csv tickets_clean.csv
Needs: pip install pandas
"""
import sys
import pandas as pd

src, dst = sys.argv[1], sys.argv[2]

# 1. read everything as text first, so nothing is guessed
df = pd.read_csv(src, encoding="utf-8-sig", dtype=str)

# 2. branch: collapse repeated spaces, trim, one casing
df["Branch"] = (df["Branch"]
                .str.replace(r"\s+", " ", regex=True)
                .str.strip()
                .str.title())

# 3. dates: day first, so 03/05/2025 is 3 May. Empty cells become NaT (empty)
for col in ("Received", "Resolved"):
    df[col] = pd.to_datetime(df[col], format="%d/%m/%Y %H:%M")

# 4. pull values out of the free text (same patterns as in Tableau)
note = df["Note"]
df["Order_ID"] = note.str.upper().str.extract(r"(SG-[0-9]{5})")[0]
df["Rating"] = pd.to_numeric(note.str.extract(r"(?:^|[^0-9/])([1-5])/5")[0]).astype("Int64")
df["Coupon"] = note.str.extract(r"([A-Z]{4,}-[0-9]{2})")[0]
df["Refund"] = pd.to_numeric(note.str.extract(r"([0-9]+[.][0-9]{2})")[0]).fillna(0)
minutes = (df["Resolved"] - df["Received"]).dt.total_seconds() / 60
df["Handling_Minutes"] = minutes.round().astype("Int64")

# 5. privacy: keep a masked note, drop the raw one
PHONE = r"0[0-9]{2}-[0-9]{3}-[0-9]{4}"
df["Has_Phone"] = note.str.contains(PHONE, regex=True)
df["Note_Masked"] = note.str.replace(PHONE, "[phone]", regex=True)
out = df.drop(columns=["Note"])
assert not out["Note_Masked"].str.contains(PHONE, regex=True).any(), "a phone number is still there"

# 6. UTF-8 with BOM, ISO dates
out.to_csv(dst, index=False, encoding="utf-8-sig", date_format="%Y-%m-%d %H:%M")

print("rows written:", len(out))
print("branches:", out["Branch"].nunique())
print("order ids found:", out["Order_ID"].notna().sum())
print("average rating:", round(out["Rating"].mean(), 2))
print("refund total:", round(out["Refund"].sum(), 2))
print("average handling minutes:", round(out["Handling_Minutes"].mean(), 1))

"""Optional: write a CSV as a Tableau .hyper extract.

Run:  python csv_to_hyper.py tickets_clean.csv tickets.hyper
Needs: Python 3.11+, pip install pandas tableauhyperapi
"""
import sys
import pandas as pd
from tableauhyperapi import (Connection, CreateMode, HyperProcess, Inserter,
                             SqlType, TableDefinition, TableName, Telemetry)

src, dst = sys.argv[1], sys.argv[2]
df = pd.read_csv(src, encoding="utf-8-sig", parse_dates=["Received", "Resolved"])


def sql_type(dtype):
    if pd.api.types.is_bool_dtype(dtype):
        return SqlType.bool()
    if pd.api.types.is_integer_dtype(dtype):
        return SqlType.big_int()
    if pd.api.types.is_float_dtype(dtype):
        return SqlType.double()
    if pd.api.types.is_datetime64_any_dtype(dtype):
        return SqlType.timestamp()
    return SqlType.text()


columns = [TableDefinition.Column(str(c), sql_type(df[c].dtype)) for c in df.columns]
table = TableDefinition(TableName("Extract", "Extract"), columns)
rows = df.astype(object).where(df.notna(), None).values.tolist()

with HyperProcess(telemetry=Telemetry.DO_NOT_SEND_USAGE_DATA_TO_TABLEAU) as hyper:
    with Connection(hyper.endpoint, dst, CreateMode.CREATE_AND_REPLACE) as conn:
        conn.catalog.create_schema("Extract")
        conn.catalog.create_table(table)
        with Inserter(conn, table) as ins:
            ins.add_rows(rows)
            ins.execute()
        n = conn.execute_scalar_query(f"SELECT COUNT(*) FROM {table.table_name}")
print("wrote", n, "rows to", dst)
