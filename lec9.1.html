🐍 למה דווקא פייתון?

בעולם ה-AI, פייתון (Python) היא השפה השלטת. כמעט כל כלי, ספרייה, ופלטפורמה בתחום מציעים ממשק (SDK) לפייתון. הסיבות:

  • 📚 ספריות עשירות – NumPy, Pandas, TensorFlow, PyTorch, ועוד
  • ממשקים פשוטים – קל לחבר בין כלים שונים
  • 👥 קהילה ענקית – תמיכה, מדריכים, ופתרונות זמינים
  • פיתוח מהיר – קוד קצר וקריא יחסית לשפות אחרות
  • 🤖 תמיכה רשמית – כל חברות ה-AI מספקות SDK לפייתון ראשון
פייתון משמשת כגשר בין הקוד שלך למודלי ה-AI השונים

הדרך הפשוטה ביותר לדבר עם LLM מקומי מפייתון היא דרך ספריית ollama. הנה דוגמה מלאה:

simple_chat.pyimport ollama

# הגדרת System Prompt

Explain concepts clearly with examples.
Respond in Hebrew (עברית)."""

# שליחת הודעה למודל
response = ollama.chat(

🔄 דוגמה 2: שיחה מתמשכת (Multi-turn)

LLM הוא חסר מצב (stateless) – הוא לא זוכר שיחות קודמות. כדי ליצור שיחה מתמשכת, אנחנו צריכים לשלוח את כל היסטוריית ההודעות בכל בקשה:

conversation.pyimport ollama

# אתחול היסטוריית השיחה
conversation_history = [
    {'role': 'system', 'content': 'You are a helpful assistant.'}
]

def chat(user_message):
    # הוספת הודעת המשתמש להיסטוריה
    conversation_history.append({
        'role': 'user',
        'content': user_message
    })
    
    # שליחת כל ההיסטוריה למודל
    response = ollama.chat(
        model='gemma4:12b',
        messages=conversation_history
    )
    
    # קבלת תשובת המודל
    assistant_message = response['message']['content']
    
    # הוספת התשובה להיסטוריה
    conversation_history.append({
        'role': 'assistant',
        'content': assistant_message
    })
    
    return assistant_message

# שימוש
print(chat("שמי אלכס"))  # "נעים להכיר, אלכס!"
print(chat("איך קוראים לי?"))  # "קוראים לך אלכס" ✓ זוכר!
⚠️ אזהרה: זיכרון הוא לא אינסופי!

ככל שהשיחה מתארכת, conversation_history גדל. ברגע שהוא חורג מחלון ההקשר של המודל, תתחיל לאבד את ההתחלה של השיחה. בפרק 10 נלמד טכניקות לניהול זיכרון חכם.

🌊 דוגמה 3: Streaming – תשובה מייצור בזמן אמת

כשמשתמשים ב-LLM, התשובה לא מגיעה בבת אחת – היא נוצרת טוקן-אחרי-טוקן. בשיטת Streaming, אנחנו מציגים כל טוקן ברגע שהוא נוצר – כמו ש-ChatGPT עושה:

streaming.pyimport ollama

def stream_response(prompt):
    # stream=True מאפשר קבלת טוקנים אחד-אחד
    stream = ollama.chat(
        model='gemma4:12b',
        messages=[{'role': 'user', 'content': prompt}],
        stream=True
    )
    
    # מעבר על כל טוקן בנפרד
    for chunk in stream:
        token = chunk['message']['content']
        print(token, end='', flush=True)
    
    print()  # שורה חדשה בסוף

stream_response("כתוב שיר קצר על ים")
✨ למה Streaming חשוב?
  • חוויית משתמש – המשתמש רואה תשובה תוך שנייה, לא מחכה 10 שניות
  • ביטול – המשתמש יכול לעצור את התשובה באמצע
  • זיכרון – לא צריך לשמור את כל התשובה בזיכרון

🔗 דוגמה 4: LangChain – ספרייה מתקדמת

LangChain היא ספרייה פופולרית שמפשטת בניית אפליקציות LLM מורכבות. היא מספקת כלים לשרשראות (chains), סוכנים (agents), זיכרון (memory), ועוד.

langchain_example.pyfrom langchain_community.llms import Ollama
from langchain.prompts import ChatPromptTemplate
from langchain.chains import LLMChain

# יצירת אובייקט המודל
llm = Ollama(
    model="gemma4:12b",
    temperature=0.3,
    num_ctx=4096  # גודל חלון ההקשר
)

# הגדרת תבנית Prompt
prompt_template = ChatPromptTemplate.from_messages([
    ("system", "You are a {role} expert. Respond in {language}."),
    ("user", "{question}")
])

# יצירת שרשרת (Chain)
chain = LLMChain(llm=llm, prompt=prompt_template)

# הפעלת השרשרת
result = chain.invoke({
    "role": "data scientist",
    "language": "Hebrew",
    "question": "מה ההבדל בין supervised ל-unsupervised learning?"
})

print(result["text"])
🎯 מתי LangChain שימושי?
  • RAG – שאלות על המסמכים שלך
  • Agents – מודל שמשתמש בכלים (חיפוש, חישוב)
  • Memory – ניהול זיכרון חכם אוטומטי
  • Complex Chains – שרשראות של פעולות

🤖 דוגמה 5: Pydantic AI – סוכן מודרני

Pydantic AI היא ספרייה חדשה (2025-2026) לבניית סוכני AI עם טיפוסים חזקים. היא מאפשרת להגדיר Tools בצורה מסודרת ולקבל תוצאות מובנות:

pydantic_agent.pyfrom pydantic_ai import Agent, RunContext
from pydantic_ai.models.ollama import OllamaModel

# הגדרת המודל
model = OllamaModel('gemma4:12b')

# יצירת סוכן
agent = Agent(
    model,
    system_prompt="You are a research assistant.",
    result_type=str
)

# הוספת כלי (Tool)
@agent.tool
def search_web(ctx: RunContext, query: str) -> str:
    """Search the web for information."""
    # לוגיקה אמיתית של חיפוש כאן
    return f"Results for: {query}"

# הרצת הסוכן
import asyncio
result = asyncio.run(agent.run("חקור את מגמות ה-AI ב-2026"))
print(result.data)

⚡ מה זה Streamlit?

Streamlit (streamlit.io) היא ספריית פייתון שמאפשרת לבנות אפליקציות ווב אינטראקטיביות בלי לדעת HTML, CSS, או JavaScript. פשוט כותבים קוד פייתון רגיל, ו-Streamlit הופך אותו אוטומטית לאתר.

אפליקציית Streamlit טיפוסית: sidebar עם פרמטרים, אזור צ'אט ראשי, ותצוגת תוצאות

למה Streamlit מושלם ל-LLM?

  • 🎨 UI מוכן – רכיבי צ'אט, סליידרים, כפתורים, טפסים – הכל מובנה
  • 🔄 ריאקטיביות – כל שינוי בפרמטר מריץ מחדש את הקוד אוטומטית
  • 💾 State management – מנגנון מובנה לזכירת מצב בין אינטראקציות
  • 🚀 פריסה קלה – אפשר להעלות ל-Streamlit Cloud בחינם
  • ויזואליזציות – תמיכה מובנית ב-Matplotlib, Plotly, ועוד

💬 פרויקט: צ'אטבוט AI מלא ב-Streamlit

בואו נבנה אפליקציית צ'אט מלאה עם LLM מקומי. זהו הקוד המלא של app.py:

app.py - קוד מלאimport streamlit as st
import ollama

# ============ הגדרות העמוד ============
st.set_page_config(
    page_title="צ'אט AI מקומי",
    page_icon="🤖",
    layout="wide"
)

# ============ אתחול מצב השיחה ============
if "messages" not in st.session_state:
    st.session_state.messages = [
        {"role": "system", "content": "You are a helpful assistant."}
    ]

# ============ Sidebar עם הגדרות ============
with st.sidebar:
    st.title("⚙️ הגדרות")
    
    model_name = st.selectbox(
        "בחר מודל:",
        ["gemma4:12b", "qwen3.6:14b", "llama4:scout"]
    )
    
    temperature = st.slider(
        "יצירתיות (Temperature):",
        min_value=0.0, max_value=2.0, value=0.7, step=0.1
    )
    
    system_prompt = st.text_area(
        "System Prompt:",
        value="You are a helpful assistant. Respond in Hebrew.",
        height=100
    )
    
    if st.button("🗑️ נקה שיחה"):
        st.session_state.messages = [
            {"role": "system", "content": system_prompt}
        ]
        st.rerun()

# ============ כותרת ראשית ============
st.title("🤖 צ'אט AI מקומי")
st.caption(f"מודל פעיל: {model_name} | Temperature: {temperature}")

# ============ הצגת היסטוריית הודעות ============
for msg in st.session_state.messages:
    if msg["role"] == "system":
        continue  # לא מציגים את ה-system
    
    with st.chat_message(msg["role"]):
        st.markdown(msg["content"])

# ============ קלט מהמשתמש + Streaming ============
if user_input := st.chat_input("כתוב הודעה..."):
    st.session_state.messages.append({
        "role": "user",
        "content": user_input
    })
    with st.chat_message("user"):
        st.markdown(user_input)
    
    with st.chat_message("assistant"):
        response_placeholder = st.empty()
        full_response = ""
        
        try:
            stream = ollama.chat(
                model=model_name,
                messages=st.session_state.messages,
                options={"temperature": temperature},
                stream=True
            )
            
            for chunk in stream:
                token = chunk["message"]["content"]
                full_response += token
                response_placeholder.markdown(full_response + "▌")
            
            response_placeholder.markdown(full_response)
            st.session_state.messages.append({
                "role": "assistant",
                "content": full_response
            })
        except Exception as e:
            st.error(f"שגיאה: {e}")

🔄 ניהול מצב עם Session State

בניגוד לסקריפט רגיל, אפליקציית Streamlit מריצה מחדש את כל הקוד בכל אינטראקציה. כדי לשמור נתונים בין ריצות, משתמשים ב-st.session_state:

session_state.pyimport streamlit as st

# אתחול ערכים התחלתיים (רק בפעם הראשונה)
if "counter" not in st.session_state:
    st.session_state.counter = 0
    
if "history" not in st.session_state:
    st.session_state.history = []

# הצגת הערכים
st.write(f"מונה: {st.session_state.counter}")
st.write(f"היסטוריה: {st.session_state.history}")

# כפתור שמגדיל את המונה
if st.button("הגדל מונה"):
    st.session_state.counter += 1
    st.session_state.history.append(st.session_state.counter)
    st.rerun()  # רענון העמוד

הבעיה: LLM שוכח הכל

כמו שלמדנו בפרק 5, LLM הוא stateless – הוא שוכח כל שיחה. אבל משתמשים מצפים שהמערכת תלמד מהם:

  • "הוא יודע שאני אוהב תשובות קצרות"
  • 📚 "הוא זוכר את המסמכים שלי"
  • 🎯 "הוא מכיר את הקוד שלנו"
  • "הוא יודע מה דיברנו לפני שבוע"

איך פותרים את זה? שלוש שכבות זיכרון:

1️⃣ זיכרון קצר-טווח (Conversation Buffer) היסטוריית השיחה הנוכחית ב-session_state
↓
2️ זיכרון ארוך-טווח (User Profile DB) SQLite / PostgreSQL – פרטי משתמש, העדפות
↓
3️⃣ זיכרון סמנטי (Vector DB + RAG) ChromaDB / Qdrant – מסמכים, ידע, embeddings

🎯 מה זה Embeddings?

Embedding הוא וקטור (רשימת מספרים) שמייצג את המשמעות של טקסט. שני טקסטים דומים יקבלו וקטורים דומים.

🎨 RAG – Retrieval Augmented Generation

RAG הוא הטכניקה שמשלבת embeddings + LLM. במקום שהמודל יענה מהידע שלו בלבד, הוא מקבל הקשר רלוונטי מהמסמכים שלך.

1️ שאלת המשתמש: "מה סעיף 7 בחוזה?" טקסט חופשי
↓
2️⃣ המרה ל-Embedding מודל embedding הופך את השאלה לוקטור
↓
3️⃣ חיפוש ב-Vector DB מוצא 3-5 קטעים דומים מהמסמכים
↓
4️⃣ הרכבת Prompt עם ההקשר שאלה + קטעים רלוונטיים
↓
5️⃣ LLM מייצר תשובה מבוססת-מקורות "סעיף 7 אומר: ..." עם ציטוט מדויק

💾 דוגמה: מערכת זיכרון לומדת

memory_system.pyimport sqlite3
import chromadb
from chromadb.utils import embedding_functions
import ollama
from datetime import datetime

class LearningMemory:
    """מערכת זיכרון שלומדת את המשתמש לאורך זמן."""
    
    def __init__(self, user_id: str):
        self.user_id = user_id
        
        # SQLite לפרטי משתמש
        self.conn = sqlite3.connect('users.db')
        
        # ChromaDB לזיכרון סמנטי
        self.chroma = chromadb.PersistentClient(path="./chroma_db")
        self.embed_fn = embedding_functions.SentenceTransformerEmbeddingFunction(
            model_name="BAAI/bge-m3"  # מצוין בעברית
        )
        self.collection = self.chroma.get_or_create_collection(
            name=f"user_{user_id}",
            embedding_function=self.embed_fn
        )
    
    def remember_fact(self, fact: str):
        """שמירת עובדה בזיכרון הסמנטי."""
        self.collection.add(
            documents=[fact],
            metadatas=[{"user": self.user_id}],
            ids=[f"fact_{datetime.now().timestamp()}"]
        )
    
    def recall(self, query: str, n: int = 3) -> list:
        """שליפת זיכרונות רלוונטיים."""
        results = self.collection.query(
            query_texts=[query],
            n_results=n
        )
        return results["documents"][0]
    
    def ask_with_memory(self, question: str) -> str:
        """שאלה עם זיכרון."""
        memories = self.recall(question)
        context = "\n".join(memories)
        
        prompt = f"""Answer using context from memory.

USER MEMORIES:
{context}

QUESTION: {question}

Respond in Hebrew."""
        
        response = ollama.chat(
            model='gemma4:12b',
            messages=[{"role": "user", "content": prompt}]
        )
        
        # שמירת הזיכרון החדש
        self.remember_fact(f"Q: {question}\nA: {response['message']['content']}")
        
        return response["message"]["content"]

# שימוש
memory = LearningMemory("alex")
memory.remember_fact("המשתמש הוא מפתח פייתון בכיר")
print(memory.ask_with_memory("איך כדאי לי לכתוב פונקציה?"))

🌐 OpenRouter – מרכזיית כל המודלים

OpenRouter (openrouter.ai) הוא שירות שמאפשר לגשת למאות מודלים דרך API אחיד.

openrouter_debug.pyfrom openai import OpenAI

client = OpenAI(
    base_url="https://openrouter.ai/api/v1",
    api_key="sk-or-v1-...",
)

models = [
    "anthropic/claude-sonnet-4",
    "openai/gpt-5",
    "google/gemini-2.5-pro"
]

for model in models:
    response = client.chat.completions.create(
        model=model,
        messages=[{"role": "user", "content": "Debug this code..."}]
    )
    print(response.choices[0].message.content)
