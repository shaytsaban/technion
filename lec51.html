מה זה API — הסבר למי שלא ראה קוד

🍽️ אנלוגיה: מסעדה

כשאתם הולכים למסעדה — אתם לא נכנסים למטבח. אתם פותחים תפריט, בוחרים מנה, המלצר מעביר למטבח, ומקבלים את האוכל. API זה בדיוק אותו דבר.

📖 API = Application Programming Interface

ממשק שמאפשר לתוכנה אחת לדבר עם תוכנה אחרת. במקרה שלנו: הקוד שלכם מדבר עם מודל AI דרך API. אתם שולחים טקסט (ה"הזמנה"), ה-AI מעבד, ומחזיר תשובה (ה"מנה").

🔄 איך זה עובד בפועל

הקוד שלכם שולח בקשת HTTP (כמו כשאתם פותחים אתר) לכתובת של ה-AI. הבקשה כוללת: (1) מפתח API שמזהה אתכם, (2) הטקסט שאתם רוצים שה-AI יעבד, (3) הגדרות כמו איזה מודל להשתמש. ה-AI מחזיר תשובה ב-JSON — פורמט טקסט מסודר.

🎯 למה זה חשוב? כי בלי API — ה-AI הוא רק צ'אט בדפדפן. עם API — ה-AI הופך לחלק מהמערכת שלכם. המשתמש לא צריך לפתוח שום דבר — הכל קורה ברקע.

16 C · מקומי

למה בכלל להריץ מודל מקומי?

🔒 פרטיות

הנתונים לא יוצאים מהמחשב שלכם. אם אתם בונים מערכת עם נתונים רגישים (רפואיים, פיננסיים, אישיים) — מקומי הוא הפתרון היחיד שמבטיח שאף אחד לא רואה את המידע.

💰 עלות

חינם לגמרי. אחרי שהתקנתם — אין עלות per-request. אין API Key, אין חיוב, אין rate limit.

🌐 בלי אינטרנט

עובד גם בטיסה, גם בלי WiFi, גם כשהשרת של OpenAI נופל. תמיד זמין.

🎓 למידה

מבינים איך מודלים עובדים מבפנים — מה זה quantization, מה זה context window, איך טמפרטורה משפיעה. ידע ששווה הרבה.

Ollama הוא כלי שמוריד ומריץ מודלי AI על המחשב שלכם בשורה אחת בטרמינל.

זהו! אחרי שהמודל ירד — אתם בצ'אט איתו.

⚡ משימה: התקינו Ollama עכשיו

Q2_K — דחיסה חזקה, איכות נמוכה, ~2GB ל-8B model

עוד פרמטרים שחשוב להכיר

📏 max_tokens

מקסימום אורך התשובה. 100 = קצר, 500 = בינוני, 4000 = ארוך. יותר tokens = יותר יקר.

🎯 top_p

חלופה ל-temperature. במקום לשלוט באקראיות — מגביל את המודל ל"הסתברות מצטברת". 0.9 = רק המילים הכי סבירות. לא צריך גם temperature וגם top_p — בחרו אחד.

🚫 stop_sequences

רשימת מילים/תווים שאם המודל מגיע אליהם — הוא עוצר. למשל: ["\n\n"] = עצור אחרי שתי שורות ריקות.

📐 presence_penalty

מעניש את המודל על חזרה על אותם נושאים. 0 = רגיל, 2 = ימנע מחזרות. טוב כשרוצים תשובה מגוונת.

🔄 frequency_penalty

דומה ל-presence_penalty אבל מעניש על חזרה על אותן מילים. טוב למניעת "דיבורים באוויר".

📋 system prompt

הוראות כלליות שמוגדרות מראש. למשל: "אתה עוזר כתיבה בעברית. כתוב בקצרה." משפיע על כל התשובות.

מה זה MCP — הסבר מלא

🔗 MCP = Model Context Protocol

פרוטוקול (סטנדרט) שמאפשר ל-AI לגשת לכלים חיצוניים — בסיס נתונים, קבצים, API של שירותים אחרים. במקום שה-AI יהיה "עיוור" למערכת שלכם — הוא יכול לראות ולפעול.

🍕 אנלוגיה

API = אתם מזמינים פיצה בטלפון (אתם מבקשים, הם מביאים).

MCP = אתם נותנים לשליח מפתח לדלת, כדי שיוכל גם להיכנס למטבח, לקחת צלחת, ולהניח את הפיצה על השולחן. ה-AI לא רק עונה — הוא ניגש למערכת ועושה פעולות.

🎯 Use Case קונקרטי ל-MatchMe

אתם פותחים את Claude בדפדפן ושואלים: "כמה דיווחים פתוחים יש לנו? תוריד את הישנים מהשבוע שעבר."

בלי MCP: אי אפשר. Claude לא יודע מה בבסיס הנתונים שלכם.

עם MCP server שמחובר ל-DB שלכם: Claude ניגש, מריץ SQL, ועונה — או אפילו מבצע פעולות (למחוק, לעדכן). הכל בהרשאות שאתם נותנים.

מה זה Hermes ואיך הוא עוזר?

🤖 Hermes = מודל AI שמבצע פעולות (Agent)

Hermes הוא מודל AI (מבוסס Llama) שאומן במיוחד להשתמש בכלים (tool use / function calling). הוא לא רק עונה על שאלות — הוא יודע לקרוא לפונקציות, להריץ SQL, ולבצע פעולות במערכת שלכם.

🔄 ההבדל בין ChatGPT ל-Hermes

ChatGPT/Claude — עונים על שאלות בטקסט. אם תשאלו "כמה משתמשים יש?" — הם יגידו "אני לא יודע, אין לי גישה ל-DB".

Hermes — כשמגדירים לו כלים (tools), הוא יודע לקרוא להם. אם תשאלו "כמה משתמשים?" — הוא יקרא לפונקציה שמריצה SQL, יקבל את התוצאה, ויענה: "יש 1,247 משתמשים".

🎯 איך משתמשים?

Hermes זמין דרך Ollama: ollama run hermes3. אחרי שהורדתם — אפשר להשתמש בו דרך ה-API של Ollama עם function calling.
