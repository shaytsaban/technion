④ BigQuery · שלמות ☁️

כמה ערכים חסרים?

COUNTIF סופר שורות שעונות על תנאי. נמדוד כמה פריטים חסרי תאריך מסירה, ונבדוק שעמודת הסטטוס מלאה.

  1. פתח את BigQuery Sandbox והתחבר עם חשבון Google.
  2. הרץ את שאילתה א' — אחוז הפריטים בלי תאריך מסירה.
  3. הרץ את שאילתה ב' — בדיקה שעמודת הסטטוס מלאה (אמור לצאת 0).
א' · שלמות תאריך המסירה
SELECT
  COUNT(*) AS total_items,
  COUNTIF(delivered_at IS NULL) AS missing_delivery,
  ROUND(COUNTIF(delivered_at IS NULL) / COUNT(*) * 100, 1) AS pct_missing
FROM `bigquery-public-data.thelook_ecommerce.order_items`;
ב' · האם הסטטוס מלא?
-- בדיקה תקינה = 0 חסרים
SELECT COUNTIF(status IS NULL) AS missing_status,
  COUNT(*) AS total
FROM `bigquery-public-data.thelook_ecommerce.order_items`;
💡 חוסר בתאריך מסירה הוא לגיטימי (פריט שטרם נמסר/בוטל) — לא כל NULL הוא תקלה. אבל NULL בעמודת מפתח או סטטוס כן ידליק נורה אדומה.

⑤ BigQuery · כפילויות ☁️

האם המפתח באמת ייחודי?

שתי בדיקות: השוואת COUNT(*) ל-COUNT(DISTINCT id) (אם שווים — אין כפילויות), ואיתור המפתחות הכפולים עצמם.

  1. הרץ את שאילתה ג' — אם שני המספרים שווים, אין כפילות במפתח.
  2. הרץ את שאילתה ד' — רשימת המפתחות הכפולים (תוצאה ריקה = בריא).
ג' · סך מול ייחודי
-- total_rows = distinct_ids → אין כפילות במזהה
SELECT
  COUNT(*) AS total_rows,
  COUNT(DISTINCT id) AS distinct_ids
FROM `bigquery-public-data.thelook_ecommerce.order_items`;
ד' · אילו מזהים כפולים?
-- מזהה שמופיע יותר מפעם אחת = כפילות. תוצאה ריקה = תקין.
SELECT id, COUNT(*) AS times
FROM `bigquery-public-data.thelook_ecommerce.order_items`
GROUP BY id
HAVING COUNT(*) > 1
ORDER BY times DESC
LIMIT 10;

⑥ BigQuery · שלמות הקשרים והיגיון ☁️

יתומים וערכים בלתי-אפשריים

בדיקת קישורים שבורים (anti-join ממודול 10), ובדיקת היגיון: מחיר שלילי או מסירה לפני הזמנה.

  1. הרץ את שאילתה ה' — פריטים שמצביעים על מוצר שלא קיים (אמור לצאת 0).
  2. הרץ את שאילתה ו' — ערכים בלתי-אפשריים: מחיר שלילי, או מסירה לפני הזמנה.
ה' · פריטים יתומים (קישור שבור)
-- LEFT JOIN + IS NULL = פריטים בלי מוצר תואם. 0 = שלמות תקינה.
SELECT COUNT(*) AS orphan_items
FROM `bigquery-public-data.thelook_ecommerce.order_items` oi
LEFT JOIN `bigquery-public-data.thelook_ecommerce.products` p
  ON oi.product_id = p.id
WHERE p.id IS NULL;
ו' · ערכים בלתי-אפשריים
-- שתי בדיקות היגיון בבת אחת
SELECT
  COUNTIF(sale_price < 0) AS negative_prices,
  COUNTIF(delivered_at < created_at) AS delivered_before_ordered
FROM `bigquery-public-data.thelook_ecommerce.order_items`;
✅ כשכל הבדיקות מחזירות 0 — בנית אמון בנתונים. זה לא "בזבוז זמן": זו ההצדקה לכל מספר שתציג אחר כך.

⑦ BigQuery · כרטיס בריאות ☁️

כל הבדיקות בשאילתה אחת

שאילתה אחת שמחזירה את כל מדדי האיכות יחד — בדיוק כמו "כרטיס בריאות" שמריצים על הטבלה לפני שבונים עליה דוח.

  1. הרץ את שאילתה ז' — סקירת איכות מלאה על טבלת העובדה.
ז' · כרטיס בריאות הנתונים
SELECT
  COUNT(*)                                  AS total_rows,
  COUNT(*) - COUNT(DISTINCT id)             AS duplicate_ids,
  COUNTIF(sale_price IS NULL)              AS missing_price,
  COUNTIF(sale_price < 0)                  AS negative_prices,
  COUNTIF(delivered_at < created_at)        AS impossible_dates
FROM `bigquery-public-data.thelook_ecommerce.order_items`;

סיימת — אתה כבר לא סומך עיוורת

  • ארבע תקלות: ערכים חסרים, כפילויות, יתומים, ערכים בלתי-אפשריים

  • כרטיס בריאות = כל הבדיקות בשאילתה אחת, לפני שבונים דוח
