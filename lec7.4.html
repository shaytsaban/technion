הגשר החכם של Google AI Studio

הסבר פשוט: איך מחברים את ה"מוח" של גוגל לקבצי האפליקציה שלנו?

בפרק 7.0 למדנו שבינה מלאכותית מקומית היא מדהימה כי היא חינמית ופרטית. אבל לפעמים, אנחנו רוצים להשתמש במוח חזק במיוחד שנמצא בענן של גוגל — Google AI Studio.

איך המוח הזה מדבר עם הקוד שלנו? באמצעות מפתח קסמים סודי שנקרא API Key (קוד גישה). תחשבו על זה כמו כרטיס VIP מגנטי שמאפשר לאפליקציה שלכם לשלוח שאלה לענן של גוגל, ולקבל תשובה מושלמת בשבריר שנייה!

שלום מהנדסים צעירים! אני סנטרי-בוט. בפרק זה נגלה בדיוק איך מחברים את המוח של גוגל ישירות לדאטה-בייס שלנו! בנינו עבורכם שיעור מורחב ומלא פלייגראונדים סופר-אינטראקטיביים כדי שתוכלו לעצב, לחבר, לבחון ולהריץ קוד במו ידיכם. מוכנים להתחיל?

חלק 2 · אבטחת מפתחות

כספת מפתחות ה-API (API Key & Env Vault)

סביבה יישומית: צרו מפתח API סודי, ראו איך הוא נראה, ונעלו אותו בתוך קובץ הגדרות סודי (.env) כדי להגן עליו מגניבות!

מפתח ה-API הוא קו המחשבה והתקציב שלכם. אם תעלו אותו בטעות ל-GitHub או תכתבו אותו ישירות בתוך קוד האתר שלכם, האקרים יוכלו לגנוב אותו ולבצע שאילתות יקרות על חשבונכם!

הפתרון המקצועי: אנחנו לעולם לא כותבים מפתח API בתוך הקוד! במקום זאת, אנחנו שומרים אותו בקובץ נפרד וסודי שנקרא .env (קיצור של Environment, כלומר משתני סביבה של השרת). השרת קורא את הקובץ הזה בזיכרון הפנימי שלו והקוד נשאר נקי ובטוח!

🔒 סימולטור כספת מפתחות ה-API:

קובץ: .env
PORT=5000
DATABASE_URL=postgresql://user:pass@localhost:5432/dating_db
GEMINI_API_KEY="ממתין למפתח..."
המפתח לא שמור. הקוד לא מאובטח!

חלק 4 · פרוטוקול מתאם

מה זה בכלל MCP?

הסבר לילדים: כבל ה-USB האוניברסלי שמחבר בין כל אפליקציה לכל מודל בינה מלאכותית!

בעבר, אם רציתם לחבר את הצ'אטבוט שלכם לדאטה-בייס של פוסטגרס (PostgreSQL), הייתם צריכים לכתוב קוד מיוחד ומורכב מאוד. ואם מחר הייתם רוצים להחליף את הבוט לבוט אחר — הייתם צריכים לכתוב את הכל מהתחלה!

כדי לפתור את זה, חברות הטכנולוגיה המציאו את ה-MCP — ראשי תיבות של Model Context Protocol (פרוטוקול הקשר של המודל).

מתאם ה-USB האוניברסלי:

חשבו על טלפון נייד. פעם, לכל חברה (נוקיה, מוטורולה, אפל) היה מטען מיוחד משלה. היום, לכולם יש כבל USB-C אחד שמטעין הכל. MCP הוא ה-USB-C של עולם הבינה המלאכותית! הוא מאפשר לכל בוט לדבר עם כל דאטה-בייס בצורה אחידה ובטוחה.

חיבור מאובטח 🔒

הבוט לעולם לא מקבל את סיסמת המנהל של הדאטה-בייס שלכם. הוא רק מבקש בקשות דרך מתאם ה-MCP, שבודק שאין כאן פירצת אבטחה.

חיסכון אדיר בקוד ⚡

לא צריך לכתוב קוד חיבור מותאם אישית. השרת של MCP מגיע עם חיבור מובנה לפוסטגרס, קבצים מקומיים ושרתי ענן חיצוניים!

חלק 6 · אתגר הקוד

אשף השלמת הקוד: חיבור ה-SDK של גוגל

סביבה יישומית: השלימו את הפרמטרים החסרים בקוד ה-SDK של גוגל כדי להפעיל את הבוט!

כשאנחנו רוצים לכתוב קוד אמיתי ב-Node.js/JavaScript כדי לחבר את הבוט שלנו, אנחנו משתמשים בחבילת ה-SDK של גוגל. ישנם 3 משתנים קריטיים שאנחנו חייבים להגדיר:

  • apiKey: מפתח הגישה הסודי שקיבלנו מ-AI Studio.
  • model: שם המוח שבו נרצה להשתמש (למשל: gemini-2.5-flash).
  • systemInstruction: ההנחיות והחוקים של הבוט שלנו.

// השלימו את המילה החסרה להגדרת המודל:

const { GoogleGenAI } = require("@google/genai");
const ai = new GoogleGenAI({ apiKey: process.env.API_KEY });

const response = await ai.models.generateContent({
model: ,
contents: "היי, כמה Matches פעילים יש היום?",
config: { systemInstruction: "You are Cobra Chadstone..." }
});
הקוד לא שלם. השלימו את שם המודל: gemini-2.5-flash הקוד תקין! 🟢
