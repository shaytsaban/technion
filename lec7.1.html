Step 1: Write Your Agent Instructions ✍️

To make an AI agent build an app, you need to write a clear **Instruction Prompt**. If your instructions are too vague (like "make a bot"), the AI won't know what styles, themes, or rules to build!

Your Turn: Write the configuration prompt for your chatbot. For example, tell it what the chatbot should be named, what emoji it should use, and how it should speak! Try typing:
"Create a space explorer bot named Cosmo using 🚀 emoji"

✍️ TASK: Write the prompt below!
Prompt Guidelines: Make sure to include the word "named" followed by your bot's name, and state which emoji it should use!

🔍 **Reader** (inspects existing codes), 🪄 **Coder** (rewrites variables), and 🚀 **Commander** (runs host servers).

🧩 QUIZ: Match Tasks to the Correct Tool!
